# 配置工作台

## 热更新与持久化

点击“应用并持久化”，后端校验当前版本及草稿，只允许表单标注为“支持热更新”的参数改变。成功后新请求使用新配置，版本递增，页面重新读取生效配置；失败保留草稿与旧运行配置。尚未应用的编辑仍只存在于页面内存。

支持 Top K、默认策略/重排开关、融合参数、候选数量、规划器数值参数、生成数值/上下文参数、评估指标/并发与裁判数值参数。密钥引用、模型名称/模式/端点、嵌入、分块、存储及目录参数变更返回 409，整个申请不部分应用。

应用会等待当前 HTTP 请求完成（包含 SSE 全部响应），期间新请求排队；构建新 planner/generator/judge 和检索/生成链路，复用原存储和索引。不会调用模型验证网络连通性。单 worker 使用；不支持多个进程同时更新同一文件。持续运行的长请求会延迟应用，断开/结束后才继续。

持久化到 `RAG_MANAGED_CONFIG_PATH`（默认 data/config/runtime.json），仅记录允许热更新的非凭据字段与版本。使用同目录临时文件、fsync 与原子替换；写入失败不切换。重启时先加载正常 .env/环境变量/Preset，再由持久化记录覆盖其中同名热更新字段；其他字段的优先级保持原规则。该目录不纳入 Git。

持久化文件损坏或包含不允许的字段会阻止启动，需要修复该文件。恢复 .env 的同名配置可在停止服务后备份并移开持久化文件。当前没有跨进程协调、版本历史回滚或对磁盘突然故障的事务保证。

API：GET /v1/config/status 返回版本、哈希、持久化状态；POST /v1/config/apply 接收 `{expected_version, preset}`，过期版本返回 409。Trace 增加 configuration 步骤记录版本/哈希，评估快照增加 config_version。

部署本批代码需要重启一次以加载新增接口；之后支持的配置无需重启即可应用。

侧栏新增“配置工作台”。读取当前 Preset 与脱敏配置哈希，按后端字段元数据生成四组表单：检索与规划、融合与重排、生成与评估、数据与索引。

- 支持布尔/枚举选择、数值、字符串、可空值和 JSON 对象编辑。参数名称与环境变量名便于开发者定位；新增注册模式自动出现在组件选项中。
- 输入时比较当前值与草稿；点击“校验草稿”检查类型、范围、跨字段约束、组件及指标名称、权重。错误展示字段定位。
- 索引相关参数标记兼容性检查提醒；这是保守提示，是否实际需要重建仍由 IndexManifest 判断。
- 草稿保存在页面内存中，校验不应用；“应用并持久化”成功后保存热更新字段。刷新会丢弃未应用草稿，“重新读取生效配置”同样丢弃草稿。
- “恢复默认设置”一键替换全部草稿字段为后端 Settings 内置默认值（不读取 .env、环境变量或当前 Preset），并清空草稿密钥引用。它与“重新读取生效配置”不同：前者恢复项目初始默认值，后者恢复当前服务实际配置。默认恢复后仍可查看差异并校验，当前运行配置和真实密钥不受影响。
- 密钥与 service_preset 不进入编辑表单。现有 Preset 环境变量引用保留在草稿请求中，校验不读取或解析密钥。
- GET /v1/config/schema 提供字段描述；POST /v1/config/draft/validate 返回 valid/errors/activation。草稿校验不读取 .env 或系统环境变量，不加载 Provider 或调用模型。
- 旧 Preset 校验 API 保留；新草稿接口返回结构化字段错误供 UI 使用。非法分组模式和未知指标会拒绝。
- 当前校验只确认配置结构和已实现的约束，不验证凭据、端点连通性或本地模型可用性。

后续可增加 Preset 文件导入/下载、版本回滚和更多组件热替换。编辑/校验与应用明确区分。
